SYSTEM OVERVIEW

Turning gestures into interfaces.

Hand-Tracking AR UI is a real-time computer vision project that uses hand landmarks and gesture recognition to control an augmented reality interface.

Instead of traditional mouse and keyboard interaction, the system interprets natural hand movements and maps them to interactive visual effects.
